## vetech-reimburse

一个报销系统示例项目，包含前后端两个子工程：

- reimburse-backend：Spring Boot 后端服务
- reimburse-frontend：Vite + Vue 前端应用

### 运行方式（简略）

- 后端：在 `reimburse-backend` 下使用 Maven 启动 Spring Boot
- 前端：在 `reimburse-frontend` 下安装依赖并启动开发服务器

### 目录结构

- reimburse-backend/
- reimburse-frontend/
